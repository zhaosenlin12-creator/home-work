# 森灵 · 打包与部署方案

> 收尾决策文档：2026-08-14
> 结论速览：**现阶段用「局域网 Web + PWA」零成本上线；工具链就绪后再打 APK / exe。**

| 使用者 | 设备 | 需求 | 推荐方案 |

## 二、阶段一（现在就能做）：局域网 Web + PWA

### 为什么先做这个
- **零成本**：不需要任何工具链，双击 `start.bat` 全家即可用
- **孩子体验接近 App**：手机浏览器打开后「添加到主屏幕」，图标全屏运行、无地址栏，孩子基本感觉不到是网页
- 数据全在自己电脑上，家庭隐私安全

### 操作步骤
1. 电脑双击 `start.bat`（首次自动装依赖 + 构建 + 预下载教材）
2. 手机连同一 Wi-Fi，浏览器访问打印出的 `http://192.168.x.x:3101`
3. 手机浏览器菜单 →「添加到主屏幕 / 添加到桌面」，生成 App 图标
   - Android Chrome：右上角 ⋮ → 添加到主屏幕
   - iPhone Safari：分享按钮 → 添加到主屏幕
4. 家长和孩子都登录一次（记住密码），之后每次直接点图标进入

### 备注
- 电脑和手机需在同一局域网；Windows 防火墙首次弹窗选「允许」
- 手机离线/外出时无法访问（数据在电脑上），这是家庭自部署的固有边界

## 三、阶段二（工具链就绪后）：Android APK（Capacitor）

### 前置环境安装（一次性，约 1GB 下载）
```bash
# 1. JDK 17（Android Gradle 需要）
#    下载: https://adoptium.net/temurin/releases/?version=17  (Windows x64 msi)

# 2. Android SDK command-line tools
#    下载: https://developer.android.com/studio#command-line-tools-only
#    解压到 C:\Android\Sdk\cmdline-tools\latest
#    配置环境变量:
#      ANDROID_HOME = C:\Android\Sdk
#      PATH += %ANDROID_HOME%\platform-tools;%ANDROID_HOME%\cmdline-tools\latest\bin

# 3. 安装 SDK 组件
sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"

# 4. 验证
java -version && adb version
```

### 打包命令（项目目录执行）
```bash
# 安装 Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/android

# 初始化（首次）
npx cap init "森灵" "com.senlin.app" --web-dir .next/standalone  # 或 out/，见下

# 构建 Web 产物并同步到 Android 工程
npm run build
npx cap add android
npx cap sync

# 打开 Android Studio 签名打包，或命令行出 APK
cd android && gradlew assembleDebug     # debug APK（可直接安装）
gradlew assembleRelease                 # release APK（需配置签名）
```

> ⚠️ Capacitor 需要 `output: 'standalone'` 或静态导出（`output: 'export'`）。
> 当前 next.config 未开启，打包前需调整（见 README 部署章节说明）。
> API 服务需指向局域网地址：打包时把 `NEXT_PUBLIC_API_BASE` 设为 `http://电脑IP:3101`。

### 注意事项
- Android 明文 HTTP 限制：调试包可访问 http，正式发布建议配 HTTPS（或局域网自签名）
- 每次改代码：`npm run build && npx cap sync`，重新出包

## 四、阶段三：桌面 exe（Tauri 2.x）

### 前置环境（一次性，约 2-3GB，耗时最长）
```bash
# 1. Rust 工具链
#    下载: https://rustup.rs  (rustup-init.exe)
rustup default stable

# 2. Windows MSVC 构建工具（Tauri 硬依赖）
#    下载: https://visualstudio.microsoft.com/zh-hans/visual-cpp-build-tools/
#    安装时勾选「使用 C++ 的桌面开发」工作负载

# 3. WebView2（Win10/11 系统自带，无需安装）
```

### 打包命令
```bash
npm install -D @tauri-apps/cli
npx tauri init      # 按提示配置（app 名、窗口尺寸）
npm run build       # 构建 Next.js
npx tauri build     # 产出 .exe 安装包（target/release/bundle/）
```

### 备注
- Tauri 产物体积小（~10MB）、启动快、内存占用低
- 与 Web 版共享同一套代码，API 指向 `http://localhost:3101` 或内嵌服务

## 五、阶段四：iOS（后续有条件再做）

- 打包 IPA **必须**有 macOS + Xcode + Apple 开发者账号（$99/年）
- Capacitor iOS 流程：`npx cap add ios` → Xcode 打开 → 签名 → Archive
- 家庭自用也可走 TestFlight（免费 90 天 / 每年 100 台设备内测）
- **建议**：iPhone 直接用 Safari「添加到主屏幕」，体验足够

```
现在      局域网 Web（start.bat）+ 手机 PWA 主屏幕图标  ← 立刻可用
↓
```

> PWA 主屏幕图标已经满足 90% 需求；APK/exe 是锦上添花，不阻塞上线。
